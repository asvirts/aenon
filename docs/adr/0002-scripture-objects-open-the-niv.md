# Scripture objects open the NIV

The world is lived history in about 27–29 AD, before the Gospels were books. The Adventurer still reads the NIV. A scripture object, a period object or person, opens the matching passage through YouVersion. The first reading grants Scripture experience, files the passage in a journal, and pays the smaller Adventurer grant at any level, in any band, as recorded in `docs/adr/0009-combat-skills-are-the-adventurer-level.md`. Later readings keep the text and grant nothing more.

A printed Bible on a table would have put a modern book into the year 28. Witnessing events with no New Testament text would have dropped the YouVersion readings the game is built to offer.

## Considered options

- A modern printed Bible as a prop in the world.
- Witnessed events only, with reading limited to scripture that already existed.
- A modern reader, and Bible objects that are allowed to look modern.
