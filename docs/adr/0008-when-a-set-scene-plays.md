# When a set scene plays

A set scene plays only while an attend step for it is the current step. Reaching its place with no such step plays nothing. The scene still plays once in the Season, the first time that step reaches it, and a later quest completes its own attend step there without a replay.

Walking in would have let a new Adventurer play a higher-band scene, such as the Capernaum stay, the Nazareth rejection, or Nain, before that band's once quests are offered. The quest paces the Gospel exchange. John at Aenon follows the same rule.

## Considered options

- Reaching the place plays the scene once, even with no attend step.
