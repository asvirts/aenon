# Experience tables for skills and Adventurer level

Trained skills rise on the Old School RuneScape table, from level 1 at 0 experience to level 99 at 13,034,431. Level 2 is 83, so one action's experience is not a level. Adventurer level still starts at 1 and still caps at 60, and it rises on the vanilla World of Warcraft table, where level 2 is 400 experience and level 60 is 4,084,700. Attack, Strength, Defence, and Hitpoints stay that Adventurer level. The rules still take a curve, so the behavior tests keep a one-point table. The playable seed uses these two tables.

A single RuneScape table for Adventurer level would have run a 99-level skill curve through bands that stop at 60. A single World of Warcraft table for the eleven skills would have stopped a 99-level skill at 60. Keeping the one-point seed would have kept one gather, one reading, or one defeat as a level.

## Considered options

- One RuneScape table for Adventurer level and for every skill.
- One World of Warcraft table for Adventurer level and for every skill.
- The one-point seed curve in the playable game.
