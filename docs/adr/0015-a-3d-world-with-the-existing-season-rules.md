# A 3D world with the existing Season rules

The Season will use real 3D characters, buildings, and terrain viewed from an elevated isometric-style camera, taking Albion Online as a visual reference. This replaces the current 2D presentation rather than only refreshing its art, while retaining the game's identity and existing gameplay rules except where explicitly revisited; movement, animation, camera, and interface are the redesign's scope. The added work of a 3D renderer and asset pipeline is accepted to obtain the desired depth and animation, beginning with a polished Aenon-to-Jordan playable area; [ADR 0016](0016-babylon-for-the-browser-world.md) selects the renderer and platform.

The user's later request for combat and gathering to feel similar to Albion extends the redesign into gameplay rules: [ADR 0018](0018-real-time-melee-with-weapon-techniques.md) selects real-time melee, and [ADR 0019](0019-renewable-wilderness-encounters-and-gathering.md) selects timed gathering and renewable wilderness encounters. The earlier preference to retain gameplay is not a prohibition against these explicitly requested changes.
