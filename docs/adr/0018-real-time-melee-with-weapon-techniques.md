# Real-time melee with weapon techniques

The Season's melee becomes real-time: selecting a hostile approaches and engages it with automatic basic attacks, hostiles attack on independent timing, and the player uses a small bar of weapon techniques with cooldowns while moving to avoid clearly signaled attacks. This replaces the paired attack exchanges and deliberately changes the combat rules to obtain the Albion-like feel the user requested; simply calling the existing swing repeatedly would not provide that behavior. Retain the Adventurer's progression, melee identity, and existing gear/stat relationships.

The first area proves three weapon-specific technique roles: offensive, defensive, and repositioning. Legendary Gear effects remain distinct from techniques; cooldowns, burns, and stuns use gameplay time and freeze while paused. Exact values are tuned through play, while [ADR 0020](0020-combat-boundaries-pause-and-recovery.md) defines threat boundaries, interruption, and recovery.
