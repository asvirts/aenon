# Playable sample asset sources

The sample's limestone dwelling, old olive, Adventurer geometry, material palettes,
surface textures, armature, skin weights, and motion clips are original work authored
for The Season. They use no stock models, third-party art packs, downloaded textures,
borrowed rigs, or motion-capture clips. The deterministic Python source is
`scripts/art/build_sample.py`; its generated `.blend` files remain editable in Blender.

Run with Blender 4.5 from any directory:

```sh
blender --background --python scripts/art/build_sample.py
```

To rebuild one asset, append `-- --asset house`, `-- --asset olive`, or
`-- --asset adventurer`. Rebuilding overwrites the matching generated `.blend` and
`.glb`; retain authored changes to those files before rebuilding from the script.
The script does not install Blender or modify the runtime, rules, or package files.

| Asset | Editable source | Runtime export | Intended scale |
| --- | --- | --- | --- |
| Limestone dwelling | `art/source/house.blend` | `public/art-sample/house.glb` | Main walls 6 × 4.5 m; about 4 m tall; awning extends the front |
| Old olive | `art/source/olive.blend` | `public/art-sample/olive.glb` | About 5 m crown width and 4.8 m height |
| Adventurer | `art/source/adventurer.blend` | `public/art-sample/adventurer.glb` | About 1.74 m tall |

All models use meters and a ground-centered origin. Blender uses Z up, with the
Adventurer and dwelling facade facing **−Y**. glTF export converts this to **+Y up
and +Z forward**. The dwelling's awning and steps extend toward +Z after export.
The olive's crown is intentionally asymmetric; its base remains centered.
Place the imported glTF container at scale 1; do not scale individual bones.

The principal mesh names are `AenonHouse`, `JordanOlive`, and `Adventurer`.
The character uses `AdventurerRig` with a Root, Pelvis, Spine, Chest, Neck, Head,
and paired UpperArm, Forearm, Hand, Thigh, Shin, and Foot bones. Limbs and body
carry actual vertex-group skin weights and an armature modifier. The original
`Idle` and `Run` animation clips are cyclic and in place; runtime navigation owns
world position and heading. Idle is 2 seconds and Run is 2/3 second at 30 fps.
Blend between the clips in the runtime; their playback alone does not translate
the character. Run is authored for **3.2 m/s at playback ratio 1.0**. Each supporting
foot moves 0.64 m backward over 0.2 seconds, canceling that forward world movement;
the swing ankle rises by at most 16 cm. The body compresses during support and
rises during brief airborne phases. An analytic two-bone solve keeps the knees
facing forward and supporting soles level; arms counter-swing in the body's
sagittal plane with bent elbows. At another travel speed, set playback ratio to
`speed / 3.2` when starting the animation group. The user's requested light run
supersedes the earlier sample walk.

The riverbank terrain, water, reeds, stones, and ground brush texture are separate
original runtime artwork authored in `src/art-sample/environment.ts`. They are
not generated by this Blender script and are not included in these three GLBs.

The static assets are joined into one mesh each with a small material palette.
Materials use glTF-compatible Principled base colors, roughness, and embedded
original 128 × 128 painted-noise image tiles for stone, wood, and woven cloth.
Foliage uses modeled folded leaf geometry and two-sided materials, without alpha
texture sorting. No Blender-only procedural shader is required at runtime.
The sample's sources do not use an AI-generated texture yet; any later AI concept
or texture work must be original to this game and separately recorded here.

Review the exported models in the actual game camera, including movement, before
calling the sample visually approved. Asset generation or successful glTF import
does not establish the visual quality, deformation quality, runtime performance,
or performance targets. Inspect both animation loops for skinning errors, feet
sliding, ground penetration, loop discontinuity, and attachment movement. Verify
that the GLB contains both named animation clips and a skin before integration.
This sample includes no combat motion, gear-swapping variants, collision geometry,
navigation mesh, or gameplay implementation.
